Primero se debe de instalar el capacitador de cordova, el cual permite el cambio de icono y el splash screen.
Luego se debe tener dos imagenes una para el icono y otra para el splash en una carpeta nombrada "resources"

![image](https://github.com/user-attachments/assets/f26c9eeb-d50a-4adf-9ec9-f66c40bd3ee7)

Luego se ejecuta un comando de cordova para meter las imagenes en la carpeta "android" del proyecto.

Luego de todo esto se realiza el apk, realizando todos los comandos ncesarios.

![7dae4931-ebe4-4c86-9c78-6a7d1b88aeb1](https://github.com/user-attachments/assets/ba507510-2cb5-4c92-8b5f-a0a7ebf822ee)

Nota: el splash en mi caso no funcionó aunque si esta en las carpetas la imagen.
